# SmartCV — AI Resume Builder

SmartCV is an intelligent, automated resume builder and analysis tool. It provides a beautiful interface for crafting modern, ATS-friendly resumes with a variety of professional templates. It also offers AI-powered feedback on your resume content to help you land your dream job!

## Features

- **Beautiful Templates:** Choose from 8 professionally designed, ATS-friendly templates (Professional, Modern, Minimal, Creative, Executive, etc.).
- **Live Preview:** See your resume update in real-time as you edit it.
- **AI Analysis & Feedback:** Get intelligent suggestions on how to improve your resume content and phrasing.
- **Export to PDF:** Download your finished resume as a high-quality PDF.
- **Resume History:** Save multiple versions of your resumes in your account.
- **Easy Customization:** Edit sections, rearrange content, and tweak the design with ease.

## Tech Stack

- **Backend:** Python, Flask, SQLite
- **Frontend:** HTML, Vanilla CSS, JS, Bootstrap 5
- **AI Integration:** Google Gemini / Langchain (or relevant AI provider)

## Setup & Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/rajthecoder07/Smart-Cv.git
   cd Smart-Cv
   ```

2. **Create a virtual environment (optional but recommended):**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows use: venv\Scripts\activate
   ```

3. **Install the dependencies:**
   ```bash
   pip install -r requirement.txt
   ```

4. **Run the application:**
   ```bash
   python app.py
   ```

5. **Open your browser:**
   Navigate to `http://127.0.0.1:5000` to start building your resume.
